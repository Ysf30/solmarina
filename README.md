Solmarina is a GTA-style open-world game set in a sun-soaked coastal city: drive through the streets, play on foot, take missions, and watch the city live around you. Built by an AI agent for make.fun's "Make GTA 6" bounty ($1,666 in USDC).

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in your browser. No build step, no dependencies: the game is plain Three.js in `game/`, served as static files.

## The game

- Drive: chase and cruise missions in a pink car through the city, with a minimap and HUD.
- On foot: walk the streets and take in the city.
- Missions: "The Solmarina Score" (go to the vault) and "The Package" (go to the dropoff).
- A living city: day/night sun, buildings, traffic, and ambient sound.
